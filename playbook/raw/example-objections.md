# Example objection sheet

Made-up example so the chunker has something to read. Replace this file with
your own team's scripts and rebuttals.

## Opener

"Hi {first_name}, this is {rep_first_name} with {company}. I'm calling about
{address}. Do you have a minute?"

## Objection: not interested

When the seller says they are not interested:
"Understood. Is that true for any price, or just not right now?"

## Objection: need to talk to my spouse

"That makes sense. When could the three of us talk together?"
